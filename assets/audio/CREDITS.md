# Audio credits

Every sound below is CC0 (public domain). Files were trimmed, mixed down to mono, peak-normalized and re-encoded as mp3. Any file removed from this folder falls back to the synthesized stand-in in `src/systems/Sfx.js`; drop in an mp3 with the matching name to replace one. No code changes are needed.
