# Audio credits

Until real files are added, every sound is synthesized in `src/systems/Sfx.js`. To replace a sound, drop an mp3 with the matching name into this folder. No code changes are needed.

| File | Use | Source | Author | License |
| --- | --- | --- | --- | --- |
| ambient.mp3 | Storm and sea loop | | | |
| click.mp3 | Any click | | | |
| pickup.mp3 | Item picked up | | | |
| send.mp3 | Item sent down or up the dumbwaiter | | | |
| unlock.mp3 | Lock opens, fuse seats | | | |
| flood.mp3 | Valves open, water rushes in | | | |
| error.mp3 | Wrong item or wrong code | | | |
| win.mp3 | Ending | | | |
| swap.mp3 | Switching character | | | |
